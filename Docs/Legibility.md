## Funcions

a function is written as

<type>
<name> ( void ) 
{
    void
}

<type>
<name> ( void ) 
{
    /*code*/
}

or 

<type>
<name>
( <args> )
{
    /*code*/
}

if there are a lot of arguments:

<type>
<name>
(
    <arg>,
    <arg>,
    <arg>,
    <arg>,
    <arg> = <value>,
)
{
    /*code*/
}

for constructors
<type>
<name>
(
    <arg>,
    <arg>,
    <arg>,
    <arg>,
    <arg> = <value>,
)
:
    <par>(<arg>),
    <par>(<arg>),
    <par>(<arg>),
    <par>(<arg>),
    <par>(<arg>),
{
    /*code*/
}
